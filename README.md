# Farm Pages — Published Trial Output

This is the **public, static deployment output** of the disposable phone-only Farm Test experiment.

- Private editable TypeScript source: https://github.com/godofthunder101/farm-test
- Public test URL (after GitHub Pages is enabled): https://godofthunder101.github.io/farm-pages/
- Entry point: `index.html`
- Build: `trial-001`

The access-word screen is **client-side interaction gating**, not true access control. The published HTML, CSS, and JavaScript can be inspected by anyone. No private game content or secrets belong here.

To publish through GitHub Pages, choose **Settings → Pages → Source: Deploy from a branch → main → /(root) → Save**. Subsequent edits to files in this repository can trigger publication. Cross-repo automated build/push is not yet configured.

## Deployment trigger

GitHub Pages has been configured to publish the `main` branch from `/(root)`. A source-branch commit is used here to check that automatic publishing starts without a desktop workflow.
